## Download & Install

> Setup notes for **Elgato Wave Link** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Elgato Wave Link** from the Start menu

## What you can use it for

- Live stream production and scene switching
- Camera, mic, and desktop source mixing
- Overlays, lower-thirds, and alert integrations
- Multi-platform RTMP output support
- Recording ISO channels for post-edit
